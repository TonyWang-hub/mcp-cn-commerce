## 不随单次成功消失的限制

- 当前 SDK 四个订单/售后原生查询已核；通用 `get_shop_info` 不支持，不作为健康检查必过项。MCP 售后列表的实际详情需通过 SDK 查询，不能假定新增了同名 MCP 详情工具。
- 订单列表只覆盖近 90 天创建订单；更早创建但今天付款的记录可能不可发现。分页完成、`amounts_complete=true` 均不能证明完整付款日覆盖。
- `business_coverage=unverified` 保留；30 分钟采集样本生成的日报只代表已观测记录，不叫整日银行到账、利润或结算单。
- 抖店 `expires_in` 的官方指南/API 描述存在冲突，需精确核对实际字段含义；位数、默认天数或成功一次不能作为单位证明。
- 自用、测试 code、服务市场订购和浏览器链路只对实际完成的部分签验。没有到期、跨日或两页样本的检查继续为“未执行”。
