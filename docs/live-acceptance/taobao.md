## 不随单次成功消失的限制

- 当前五个订单/退款 SDK 操作为 documented，shop info 仅 `transport_only`，不能整体签成所有 TOP API 已核。
- 创建/订单增量有近三个月可见范围，默认交易 type 不等于所有交易类型；退款列表未明确的历史范围不能套用订单三个月限制。
- TOP API 不承诺稳定快照。结果变化、分页/详情不一致必须保留失败或不完整证据，不能凭终页和总数称全量账务完成。
- payment 受售后影响，观察净额不是历史银行现金、结算或利润；`business_coverage=unverified` 保留。只采小窗口时不称完整自然日报。
- 缺少两页、跨日、真实到期或获准撤销样本时对应项继续未执行，不为凑样本擅自下单/退款。

依据：[TOP 合同](../taobao-contract.md)、[数据口径](../data-contracts.md)、[SDK 能力表](../sdk-integration.md#catalogue-and-evidence-status)。与同一次 Pro 试点共用授权和证据，不重复开户或平台调用。记录只保存一致匿名 ID、字段类型、金额/时间口径、固定错误类别和私有证据哈希；原始响应和买家资料留在获准私有目录。
