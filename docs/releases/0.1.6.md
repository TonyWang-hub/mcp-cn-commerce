# mcp-cn-commerce Core 0.1.6 release notes

Release target: `v0.1.6`. Check the [GitHub Release](https://github.com/TonyWang-hub/mcp-cn-commerce/releases/tag/v0.1.6), [PyPI 0.1.6](https://pypi.org/project/mcp-cn-commerce/0.1.6/) and [release-readiness record](https://github.com/TonyWang-hub/mcp-cn-commerce/blob/main/docs/release-readiness.md) for artifact availability and the corresponding source commit.

## English

Core 0.1.6 documents operation-level capability evidence through `contract_status`, `supported` and `live_verified` in MCP tool descriptions. Operations marked unsupported are rejected before a platform request; retained compatibility entries remain explicitly unverified. The package provides read-only merchant platform queries; it does not expose merchant platform write, update or delete operations.

The SDK includes explicit-credential clients and an operation catalogue, plus deterministic `build_daily_report` aggregation that reports source coverage and preserves unknown or incomplete amounts. Youzan remains SDK-only and is not a ninth MCP entry point. Pinduoduo merchant SDK reads remain unsupported until the complete official business schema is available.

The package contains eight MCP platform entry points and 155 registered tools. This is a directory count that includes compatibility and unsupported entries; it does not describe the number of supported or merchant-verified operations. Real merchant API acceptance and back-office reconciliation have not been performed. All SDK `live_verified` values are `false`.

Runtime lock updates keep MCP / mcp-types `2.3.0` and httpx2 / httpcore2 `2.13.1` in compatible pairs. Pydantic `2.13.5` supplies its matching `pydantic-core` version through package metadata, without a redundant direct lock entry. CI is configured to test Python 3.11, 3.12 and 3.13 in separate jobs; consult the CI run and readiness record for results tied to the exact source revision.

Pro is a separate, private offering with its own release and acceptance evidence. It is not included in Core 0.1.6; the existing free seed-user beta commitment remains in effect.

Install in a project virtual environment with `python -m pip install "mcp-cn-commerce==0.1.6"`. For source installation, verify that the `v0.1.6` tag exists before checking it out. See the [installation guide](https://github.com/TonyWang-hub/mcp-cn-commerce/blob/v0.1.6/README_en.md#quick-start) for commands.

## 简体中文

Core 0.1.6 在 MCP 工具描述中提供 `contract_status`、`supported` 和 `live_verified` 操作级能力证据。标记为不支持的操作会在发送平台请求前被拒绝；保留的兼容入口仍明确标记为未验证。此包提供商家平台只读查询，不提供商家平台写入、更新或删除操作。

SDK 包含显式凭证客户端和操作目录，以及确定性 `build_daily_report` 汇总；日报会标记数据来源覆盖，并保留未知或不完整金额。有赞仍为仅 SDK 接入，不构成第九个 MCP 平台入口。拼多多商家 SDK 查询在取得完整官方业务 schema 前保持不支持。

此包包含 8 个 MCP 平台入口和 155 个已注册工具。这是包含兼容项和不支持项的目录数量，不代表支持或通过真店验证的操作数量。尚未执行真实商家 API 验收和后台对账；所有 SDK 的 `live_verified` 均为 `false`。

运行依赖锁组配套更新：MCP / mcp-types `2.3.0`，httpx2 / httpcore2 `2.13.1`。Pydantic `2.13.5` 通过包元数据约束匹配的 `pydantic-core` 版本，不再重复直接锁定子依赖。CI 分别配置 Python 3.11、3.12、3.13 作业；具体提交的结果以对应 CI 运行和发布准备记录为准。

Pro 是独立私有产品，有自己的版本发布和验收证据，不包含在 Core 0.1.6 中；已承诺的免费种子用户内测安排继续有效。

在项目虚拟环境中执行 `python -m pip install "mcp-cn-commerce==0.1.6"` 安装。源码安装前须先确认 `v0.1.6` tag 已存在，再检出该 tag。命令见[安装说明](https://github.com/TonyWang-hub/mcp-cn-commerce/blob/v0.1.6/README.md#安装)。
